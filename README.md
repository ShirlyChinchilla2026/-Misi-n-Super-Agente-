# Misión:Super-Agente
Se trata de que el usuario entre las edades de 8 y 10 años es un agente que con forme a misiones resuelve el misterio usando herramientas proporcionadas para resolver los acertijos para pasar de nivel y al final saber su rango de agente. 
# Fase-1 ANALISIS
# -Requerimientos Funcionales- 

- Seleccionar herramienta inicial -
El sistema deberá permitir al usuario elegir una herramienta inicial entre las siguientes opciones: 
° Linterna potente. 
° Lupa de detective. 
° Radio de comunicación.

- Modificar la historia según decisiones -
El sistema deberá presentar diferentes mensajes o rutas narrativas dependiendo de la decisión seleccionada por el usuario.

- Validar entradas del usuario -
El sistema deberá verificar que las opciones ingresadas correspondan a los valores permitidos. 

- Finalizar la partida -
El sistema deberá finalizar el juego cuando: 
° Se completen los tres escenarios. 
° El usuario pierda todas sus vidas.

- Generar reporte de misión -
El sistema deberá mostrar un resumen con: 
° Nombre del agente. 
° Puntos acumulados. 
° Vidas restantes.

# -Requerimientos No Funcionales-

- Claridad de mensajes -
Los mensajes mostrados deberán utilizar un lenguaje amigable, sencillo y motivador. 

- Seguridad de datos -
El sistema solo almacenará temporalmente la información necesaria para la partida actual. 

- Experiencia de usuario -
El juego deberá mantener una experiencia entretenida mediante mensajes interactivos, recompensas y retroalimentación constante.

- Robustez -
El sistema no deberá cerrarse ni bloquearse cuando el usuario ingrese datos incorrectos. 

- Mantenibilidad -
El código fuente deberá estar organizado en módulos o funciones para facilitar futuras modificaciones.
